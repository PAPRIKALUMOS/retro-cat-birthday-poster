# Choosing the Party Accessories

Each file in `assets/party-accessory-sets/` is one complete pair: a conical hat and its matching collar. By default the pair travels together; where the cat's own item holds one spot (see below), only the other part is used.

## Cats that already wear something

What the cat wears in the photo (sweater, harness, bandana, bow tie, collar, tag, hat, headband, ear decoration) is part of its identity and stays on the poster as a distinguishing feature.

- **Different spot from the party items** (body clothing, harness, tags): keep it exactly as shown; the party collar sits over the neckline naturally.
- **Same spot as the party hat** (a hat, headband or ear decoration on the head): the cat's own item stays and the party hat is omitted.
- **Same spot as the party collar** (any collar, beaded or plain, tag, necklace, bandana, bow tie or neck ribbon): the cat's own item stays and the party collar is omitted. The two never stack; there is no exception for thin collars or tags.
- What you tell the user must match the brief you send: if you say a party item is left out, the brief must not contain it.
- Name what the cat wears in the brief so it is rendered as in the photo, and state which party item is omitted. Use only the party items that are used: attach the accessory file only if at least one of its two parts is used, and attach none when both spots are taken. The poster stays festive through the cake and the rest of the scene.
- Say it at delivery ("your cat already wears [item], so I kept it and left out the party [hat/collar]; tell me if you would rather swap it for the party item"). If the user prefers the party item, replace the original: an explicit request overrides this rule.
- An item the cat already wore is not a "doubled" party item; only a second party hat or collar counts as doubled.

## How to choose

1. Find the coat family of the cat that will wear a party item in the table below and take one of the recommended sets. Look at an image file only to break a tie.
2. Check contrast with the colors around the cat's head and neck, and harmony with the poster's pale yellow-blue palette. When unsure, take the set with the strongest contrast to the cat's dominant head and neck color.
3. Prefer clean construction. When the pose or clothing makes the neck area awkward, choose a set with a simple band collar (marked "band" below).
4. For several honorees, pick distinct but coordinated sets unless the user wants matching ones.
5. Attach only the chosen file(s), never the directory or unused alternatives. Do not mix a hat from one set with a collar from another.

## Coat families

| Coat | Recommended | Avoid |
|---|---|---|
| Black, dark brown, dark gray | `multicolor-star`, `red-glitter-star`, `gold-pink-glitter`, `pink-white-gingham` | `blue-gold-stripe` (navy blends with dark fur) |
| White, cream | `red-glitter-star`, `blue-gold-stripe`, `green-white-stripe` | `multicolor-star`, `pink-white-gingham`, `lilac-star` (pale base, low contrast) |
| Orange, ginger | `blue-gold-stripe`, `green-white-stripe`, `lilac-star` | `gold-pink-glitter`, red sets |
| Gray, blue-gray, silver | `gold-pink-glitter`, `red-white-stripe`, `pink-white-gingham` | `silver-coral`, `lilac-star` |
| Brown tabby, tortoiseshell | `blue-gold-stripe`, `green-white-stripe`, `lilac-star` | `multicolor-star` (too busy against a busy coat) |
| Black-and-white, calico, tuxedo | `red-glitter-star`, `green-white-stripe`, `blue-gold-stripe` | none |
